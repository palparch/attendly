# attendly
An AI powered attendance tracking system, using facial recognition.
Makes it easy for both students and teachers to manage and track attendance.

Prototype idea (so far):
* Students scan their faces at beginning of the day.
* The program detects the face and marks that particular student as "present" for the day.
* This data is then saved in the database for tracking the attendance.
* At the end of the day, students will be required to scan their faces again before leaving the institute.
* If a student doesn't scan their face before leaving, they'll be marked for half-day presence.
* The recorded attendance data will be accesible to the individual students, as well as the class teacher.
* It will also have an attendance predictor, for making it easy to maintain a certain attendance criteria (popularly, 75%).
